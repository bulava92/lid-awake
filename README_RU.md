# Lid Awake

[English version](README.md)

Lid Awake — утилита для строки меню macOS, которая позволяет MacBook продолжать работу после закрытия крышки.

> Не кладите MacBook в сумку, пока Lid Awake включён. Закрытый ноутбук может продолжать работать и нагреваться.

## Возможности

- Постоянный режим до ручного отключения.
- Временный режим на 15 минут, 1 час, 8 часов или произвольное время.
- Настраиваемая максимальная длительность временного режима; недоступные варианты в меню отключаются.
- Работа только от адаптера, порог батареи и защита от перегрева.
- Блокировка экрана и отключение дисплеев при закрытии крышки.
- Звук при закрытии крышки с отдельной настройкой громкости.
- Нативные уведомления macOS.
- Русский и английский интерфейс.
- Событийное отслеживание крышки через IOKit с редкой резервной проверкой.
- Разные значки для постоянного и временного режимов, ожидания питания, низкого заряда, перегрева и выключенного состояния.
- Диагностика, ротация журналов, CLI, проверка обновлений, ad-hoc подпись и подготовка к Developer ID.

## Структура меню

В главном меню находятся текущий режим, «Включить», «Выключить», «Временный режим», «Настройки», «Диагностика», «Открыть журнал», «Проверить обновления» и «Выход».

Все параметры собраны в **Настройки**:

- Только при подключённом питании
- Блокировать экран при закрытии крышки
- Звук при закрытии крышки
- Громкость звука
- Защита от перегрева
- Уведомления
- Запускать при входе
- Отключать при уровне батареи
- Максимальная длительность временного режима
- Язык

## Установка

```bash
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/bulava92/lid-awake.git
cd lid-awake
zsh ./install.sh
```

Для уже загруженного репозитория:

```bash
cd ~/Projects/lid-awake
git pull
zsh ./install.sh
```

Установщик собирает проект, запускает тесты, удаляет старые варианты установки, создаёт bundle приложения и агента, применяет ad-hoc подпись при отсутствии Developer ID, устанавливает LaunchAgent, возвращает `disablesleep` в безопасное состояние и проверяет результат установки.

## Разрешения macOS

Текущая версия блокирует экран через `CGSession` и **не требует разрешения «Универсальный доступ»**. Старые версии использовали эмуляцию клавиш. Если в разделе **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** осталась старая запись `lid-awake-agent`, её можно удалить.

Фоновый агент может запросить разрешение на уведомления, когда уведомления включены.

## Временный режим

В подменю доступны стандартные интервалы, произвольная длительность и пункт «Отменить временный режим». Отмена временного режима полностью выключает Lid Awake.

Запрошенная длительность не может превышать максимум из настроек. Стандартные варианты, превышающие максимум, отображаются неактивными.

## CLI

```bash
lid-awake on
lid-awake off
lid-awake for 3600
lid-awake cancel-timer
lid-awake status
lid-awake settings
lid-awake diagnostics
lid-awake version
```

## Журналы и диагностика

- Журнал агента: `~/Library/Logs/Lid Awake/agent.log`
- Предыдущий журнал агента: `~/Library/Logs/Lid Awake/agent.log.1`
- Журнал событий: `~/Library/Application Support/Lid Awake/events.log`
- Предыдущий журнал событий: `~/Library/Application Support/Lid Awake/events.log.1`
- Последнее обнаруженное закрытие крышки: `~/Library/Application Support/Lid Awake/last-lid-close.txt`

Журналы ротируются при размере около 1 МБ. Диагностика показывает текущий режим, питание, батарею, температурное состояние, путь агента и время последнего закрытия крышки.

## Обновления

Пункт **«Проверить обновления…»** получает последний GitHub Release. При наличии новой версии можно сразу открыть страницу релиза.

## Версия

Файл `VERSION` является единственным источником версии. Перед сборкой `install.sh` генерирует `Sources/LidAwakeCore/BuildVersion.swift` и записывает ту же версию в оба bundle.

## Подпись

Без переменной `SIGN_IDENTITY` приложение и агент получают локальную ad-hoc подпись. Настоящая Developer ID-подпись и нотарификация описаны в [SIGNING.md](SIGNING.md).

## Удаление

```bash
zsh ./uninstall.sh
```

Скрипт восстанавливает штатный сон и удаляет приложение, агент, LaunchAgent, helper, CLI, настройки и журналы.
